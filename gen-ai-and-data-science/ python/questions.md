# Python — Interview Questions and Small Exercises

1. Validate whether an email ID is valid or not.
2. Reverse a string.
3. Reverse a string that contains multiple sentences.
4. Compute the factorial of a number.
5. Compute the nth Fibonacci number.
6. Check whether a string is a palindrome.
7. Remove duplicates from a list.
8. Remove duplicates from a list without using built-in functions.
9. Given a string, write a Python program to count the frequency of each character and store it in a dictionary.
10. Given a string that contains multiple sentences, write a Python program to count the frequency of each character and store it in a dictionary.
11. Given a dictionary, find the top 3 keys with the highest values.
12. Provide Python pandas code to create a DataFrame.
13. Given a DataFrame `df` with columns 'Name', 'Age', and 'Score':
    a. Filter the DataFrame to select only students who scored above 80.  
    b. Sort the filtered DataFrame by 'Score' in descending order.  
    c. Define a function that calculates a grade based on the score.  
    d. Impute/fill missing values in a DataFrame column with the column mean.
14. Flatten a nested list.
15. Python code to find the largest and second largest elements of a list.
16. Count the frequency of each element in a list.
17. Sort the values of a dictionary by value.
18. Find the maximum occurring element in a dictionary (or list).
19. Given a list, implement the following operations:
    - add(item): Add item to the end of the list.  
    - insert(index, item): Insert item at the specified position.  
    - get(index): Retrieve item by index.  
    - remove(item): Delete the first occurrence of item.
